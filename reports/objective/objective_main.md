## 口径备注

- 抽取失败：status ≠ success 或无法抽出合法选项字母；失败题记 0 分计入正确率；分母 3655 = 731 题 × 5 子集。
- 扣除猜测（逐题版）：corrected = mean_q((x_q − 1/k_q)/(1 − 1/k_q))，k ∈ {4,5}；与汇总版 (acc−mean(1/k))/(1−mean(1/k)) 在混合 k 下不等价，本数据两版差 ≤0.11pt、排名不变；修正假设乱猜均匀 1/k，对有位置偏好的模型只是近似。
- 打乱掉分含"数据集位置偏置 × 模型位置偏好"成分：free 题 gold 原位置偏前（A154/B150/C156/D121/E86），打乱将其均匀化，掉分 = 位置偏好效应 + 3 次打乱的抽样噪声。
- McNemar 只用人人间独立的 orig 731 题；s1–s3 是同一批题的重复测量，不混入配对检验，其信息由配对置换检验（题级均值差）补足。
- 打乱一致性含 orig 共四次（Spec 字面为打乱 3 次）；任一次抽取失败即整题计"不一致"（失败共 4 例，可忽略）。
- 温度 0 + 固定 seed 不保证 API 端可复现（glm-5.2 rep 与 orig 同答案率仅 94.5%），噪声底即为此而测。
